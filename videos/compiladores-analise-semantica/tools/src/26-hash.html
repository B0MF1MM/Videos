Função de hashing: 3 passos
hash.c
#define SHIFT 2int hash(char *chave) { int temp = 0; while (chave[i] != '\0') temp = ((temp << SHIFT) + chave[i]) % TAMANHO; return temp;}
exemplo: chave "ab", TAMANHO = 211
1 · caractere → inteiro
'a' = 97 'b' = 98
2 · combina: desloca e soma
97 → (97 << 2) + 98 = 486
3 · ajusta ao tamanho: resto da divisão
486 % 211 = 64 → casa 64
Tamanho primo: para 200 casas, use 211 (o menor primo maior que 200).
