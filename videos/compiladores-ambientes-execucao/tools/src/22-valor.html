Passagem por valor
avalia o argumento e copia o valor para o parâmetro
• único mecanismo de C; básico em Pascal e Ada
• C/Pascal: parâmetro = variável local com valor inicial
• mudar o parâmetro não muda o argumento
• Ada: nem dá para atribuir ao parâmetro
void troca(int a, int b) { int t = a; a = b; b = t; } troca(x, y);
