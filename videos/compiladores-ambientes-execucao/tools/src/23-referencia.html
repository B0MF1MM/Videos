Passagem por referência
passa a localização: o parâmetro vira outro nome para o argumento
void troca(int &a, int &b) { int t = a; a = b; b = t; } troca(x, y); // C++
FORTRAN77: o único
Pascal: var
C++: &
o compilador:
1. calcula o endereço do argumento e guarda no registro
2. transforma cada uso do parâmetro em acesso indireto

x
21
y
