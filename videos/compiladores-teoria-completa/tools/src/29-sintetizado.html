Geração como atributo sintetizado
cada nó recebe:
• nome: onde fica o resultado
• código: o que calcula esse resultado
código do nó = código dos filhos
+ a nova instrução do próprio nó
mas não é prático
• muitas cópias de cadeias
• melhor emitir trechos direto num arquivo
• depende muito de atributos herdados
nome: t1
código: 1 instrução
nome: t2
código: 2 instruções
o código sobe até a raiz
