void setup() { pinMode(13, OUTPUT); // pino 13 = saída}void loop() { digitalWrite(13, HIGH); // acende delay(1000); // espera 1 s digitalWrite(13, LOW); // apaga delay(1000); // espera 1 s}
setup()roda uma vez ao ligar · configura pinos e serial
loop()repete para sempre · a lógica do sistema
pinMode(pino, OUTPUT/INPUT) digitalWrite(pino, HIGH=5 V / LOW=0 V)
digitalRead(pino) → 1 ou 0 delay(ms) → 1000 = 1 s
