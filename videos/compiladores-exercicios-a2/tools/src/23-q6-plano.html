QUESTÃO 6
código de três endereços para um for com if / else
enunciado
for (i = 0; i < 4; i++) if (i < 2) a = a + 1; else a = a + 2;
→
como while
i = 0;while (i < 4) { if (i < 2) a = a + 1; else a = a + 2; i++;}
L1 · início do laço
L3 · else
L4 · fim do if
L2 · saída
Um rótulo para cada lugar para onde se pula: laço (início e saída) + if (else e fim).
